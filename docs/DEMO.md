> 目标：让观众在 3 分钟内看懂「拆解 → 复刻 → 10 变体」，并记住「拆解免费，复刻上云端」。
> 当前 demo 无需模型 Key；所有素材本地加载。

## 0. 演示前 30 秒

```bash
npm install
npm run build
npm run preview     # http://127.0.0.1:4173
```

检查：

- 首页三张案例卡能自动播放；
- `#/case/glow` 的成片能播放；
- 工作台拆解进度能跑完（约 5 秒）。

如果现场网络不稳：全程使用本地 URL，不要打开平台链接；案例卡与成片都在本地。

## 4. 常见质疑与回答

**Q：这不就是抄袭工具吗？**
A：只复刻结构与节奏，不搬运原片画面、音乐和文案；不做真人换脸；成片带 AI 标识。参考片只用于分析，不进入成片。

**Q：和 Hypit 有什么区别？**
A：Hypit 强在 Agent 生成工作流；ViralForge 把入口前移到「免费拆解 + 可分享报告」，并补上电商最痛的商品一致性和 10 条变体成本账单。两者不共享代码。

**Q：为什么拆解免费？**
A：拆解只跑视频理解，不调用生成模型，边际成本接近 0；它是拉新和传播入口。复刻与批量变体才需要模型和算力。

**Q：现在能直接生成吗？**
A：这个 demo 的成片是预渲染资产，结构分析是真实计算；接入模型 Key 后同一套 VFML 与渲染管线即可切换。我们不会把预置内容伪装成实时生成。

**Q：10 条变体的成本怎么算？**
A：按镜头生成次数 × 模型单价估算，逐条列在卡片和账单里；演示环境不产生真实模型费用。

## 1. 摘要

ViralForge 是一个 **Agent-native 的爆款短视频拆解与复刻工作台**。

它把一条爆款视频拆成一份结构化的「爆款基因」：前 3 秒钩子、镜头节奏、字幕风格、BGM 卡点、情绪曲线、转化话术；再以「词」为锚点，把结构保留、内容替换，生成可编辑的工程文件；最后一条命令产出 10 个变体，用于广告 A/B 测试，每条标明成本。

产品采用 **开源 + 云端** 的双层结构：

- **开源**：Agent Skill、MCP、CLI、拆解引擎、报告格式、FFmpeg 合成管线、商品参考图基础约束、本地小批量变体。
- **云端（WearAI）**：品类配方库、托管模型、商品/角色一致性模型、批量拆解、大批量多语言变体、模板库。

商业模式与 Hypit 已被验证的路径一致：**用免费、可传播的拆解做拉新，用复刻与批量生成的模型/算力做付费转化。**

## 2. 背景与问题

### 2.1 用户的真实痛点

商家和账号运营每天都要做大量短视频。他们最大的问题不是「不会剪」，而是 **「不知道什么会火」**。

今天，拆解爆款是运营人员正在手工做的事：

1. 刷到一条爆款，保存下来；
2. 反复看前 3 秒，猜它为什么留人；
3. 手动记镜头、抄文案、找同款 BGM；
4. 用自己的产品翻拍一条；
5. 换个钩子再拍几条，投流测试。

这个过程耗时、依赖经验、无法规模化，而且拆解结论留在个人脑子里，团队无法复用。

### 2.2 现有工具的缺口

| 类型 | 代表 | 缺口 |
| --- | --- | --- |
| 通用AI视频生成 | Sora、可灵、Veo | 黑盒生成，不可拆解，不可精确复刻结构 |
| 模板剪辑 | 剪映模板、CapCut | 只能套模板，不能解释「为什么」 |
| Agent 视频工具 | Hypit、OpenMontage | 强在生成与工作流，缺少面向电商的拆解报告、商品一致性与批量成本控制 |
| 数据工具 | 蝉妈妈、灰豚 | 给数据，不给可执行的复刻工程 |

**ViralForge 的切入点：先把「为什么爆」变成一份可分享、可编辑、可执行的结构化资产，再把复刻与批量变体接上。**

### 2.3 为什么是现在

- 短视频投放从「拍一条」变成「一周测 50 条」，变体供给是刚需。
- 多模态理解（镜头切分、ASR、节拍检测、多模态标注）成本已经低到可以免费拆解。
- Agent（Claude Code、Codex、Cursor、OpenClaw）成为新的软件入口，Skill + MCP + CLI 是自然的分发形态。
- Hypit 已验证「开源拉新 + 云端模型服务变现」的路径：2026 年 4 月成立，第三方平台 TrustMRR 显示 MRR 约 $1.75 万（847 订阅），并已获风投。

## 3. 产品定位

### 3.1 定位

> **面向跨境电商与创作者的 AI 营销创意工具。**
> 不是「又一个 AI 视频生成器」，而是「爆款结构提取器 + 可编辑复刻工作台 + 变体工厂」。

### 3.2 目标用户

| 用户 | 场景 | 关键诉求 |
| --- | --- | --- |
| 电商商家 / DTC 品牌 | 每天上新、投流、测素材 | 低成本产出大量可投放变体 |
| 账号运营 / MCN | 追热点、拆对标账号 | 快速理解爆款结构并复刻 |
| 广告投放 | Meta/TikTok/抖音投放 | 批量 A/B、明确单条成本 |
| 开发者 / Agent 用户 | 接入自己的工作流 | Skill / MCP / CLI、可编程 |

### 3.3 价值主张

- **对商家**：把「拆解爆款」从 2 小时人工变成 90 秒报告，把「做 10 条测试素材」从 2 天变成 5 分钟。
- **对团队**：拆解结论变成可分享的报告卡片和可复用工程，不再依赖个人经验。
- **对生态**：开源拆解与合成管线，任何 Agent 都能调用；云端提供模型、模板与一致性能力。

### 3.4 产品漏斗

```
免费、可传播、可离线                 付费、需要模型与算力
┌─────────────────────┐      ┌──────────────────────────┐
│  ① 拆解              │      │  ② 复刻                   │
│  贴链接 → 爆款基因    │ ───▶ │  保留结构，替换产品/脚本   │
│  报告卡片（可分享）   │      │  可编辑工程 + 成片         │
└─────────────────────┘      └────────────┬─────────────┘
                                          │
                                          ▼
                               ┌──────────────────────────┐
                               │  ③ 批量变体               │
                               │  10 个版本 / A/B 测试     │
                               │  每条标成本               │
                               └──────────────────────────┘
                                          │
                                          ▼
                               WearAI 云端：模板库 / 33 个模型 /
                               商品与角色一致性 / 大批量 / 多语言
```

**拆解不调用生成模型，几乎零成本，是拉新和传播的入口；复刻需要模型和算力，是导向 WearAI 付费的入口。**

## 5. 三层能力

### 5.1 第一层：拆解（免费、可离线）

**输入**：抖音 / TikTok / 小红书 / YouTube Shorts 链接，或本地视频。

**处理**：

1. 下载/解码，抽帧、抽音；
2. 镜头切分（PySceneDetect / TransNetV2 / OpenCV 直方图）；
3. 语音识别与词级对齐（WhisperX，可选降级）；
4. BGM 节拍检测（librosa）；
5. 多模态模型逐镜标注：钩子、节奏、情绪、话术、卖点露出；
6. 结构化成「爆款基因 JSON」。

**输出**：

- 爆款基因报告：前 3 秒钩子、镜头节奏曲线、字幕风格、BGM 卡点、情绪曲线、转化话术；
- 一张可分享的报告卡片（公开页 / 图片）；
- 可下载的 `dna.json`。

**关键指标**：90 秒内出报告；拆解边际成本趋近于 0；报告分享率。

### 5.2 第二层：复刻（付费入口）

**输入**：一份基因 + 你的产品图、卖点、脚本、配音/授权数字人。

**处理**：

- 保留结构（镜头顺序、时长关系、钩子位置、卡点）；
- 替换内容（产品、口播、字幕、场景、人物）；
- 以词为锚点重排时间线；
- 商品参考图约束每个镜头，保证商品一致性；
- 生成可编辑工程文件（不是只给 MP4）。

**输出**：`project.json`（VFML）+ 素材 + 字幕 + 分镜表 + MP4。

**关键指标**：3 分钟内出片；可编辑率 100%（每个镜头都能改）；商品一致性人工抽检通过率。

### 5.3 第三层：批量变体（规模化）

**输入**：一条复刻工程 + 变体维度（钩子 × 人群 × 卖点 × 场景 × 平台比例）。

**处理**：

- 一条命令生成 10 个版本；
- 只重生成被改动的镜头（选择性重生成）；
- 镜头级并行渲染；
- 每条记录模型、镜头数、耗时、成本；
- 自动加 AI 生成标识。

**输出**：10 条可投放视频 + 变体矩阵 + 成本账单。

**关键指标**：10 条 ≤ 5 分钟；单条成本可解释；批量失败可重试。

## 7. 技术架构

### 7.1 总览

```
输入：爆款链接 / 本地视频 + 商品图、卖点、素材
        │
        ▼
① 拆解（免费、可离线）
   抽帧/抽音 → 镜头切分 → 词级对齐 → 节拍检测 → 多模态逐镜标注
        │
        ▼
爆款基因 JSON（VFML.dna） ──▶ 报告卡片（免费、可分享、可下载）
        │
        ▼
② 改写 / 复刻（付费）
   保留结构，替换商品、脚本、配音、授权数字人
   商品参考图约束 + 词锚点重排 + 选择性重生成
        │
        ├──────────────▶ WearAI 云端（付费）
        │                 8 大品类配方库 / 33 个托管模型 /
        │                 商品与角色一致性 / 大批量 / 多语言
        ▼
③ 生成（可插拔模型）
   Seedance / 可灵 / Wan2.2 / Flux / 开源 TTS
        │
        ▼
④ 渲染
   FFmpeg 优先（字幕、配乐、多尺寸）/ 并行 / 只重做改动镜头 / AI 标识
        │
        ▼
输出：可编辑工程文件 + MP4 + 每条成本账单
```

### 7.2 拆解流水线

| 阶段 | 开源实现 | 云端增强 |
| --- | --- | --- |
| 下载 | yt-dlp + 本地上传 | 多平台、代理、批量 |
| 镜头切分 | OpenCV 直方图 / PySceneDetect | TransNetV2 |
| 语音 | WhisperX（可选） | 多语种、说话人分离 |
| 节拍 | librosa | 版权曲库匹配 |
| 标注 | 规则 + 本地小模型 | 多模态大模型逐镜标注 |
| 报告 | 模板化 JSON → 卡片 | 品类配方、行业基准 |

降级策略：没有 ASR 时，用字幕/OCR/镜头结构出报告；没有多模态模型时，用规则模板；没有网络时，用样例库。

### 7.3 VFML：以词为锚点的视频工程格式

核心原则：**词是锚点，秒是结果。** 改一句台词，镜头、字幕、节奏一起重排，而不是手动拖时间轴。

```json
{
  "version": "0.1",
  "meta": {
    "id": "glow-7d",
    "title": "熬夜脸，还有救",
    "ratio": "9:16",
    "duration": 15,
    "aiDisclosure": true
  },
  "productRefs": [
    { "id": "serum", "image": "assets/serum.png", "lock": ["logo", "color", "shape"] }
  ],
  "words": [
    { "text": "熬夜", "start": 0.2, "end": 0.6 },
    { "text": "还有救", "start": 0.6, "end": 1.1 }
  ],
  "shots": [
    {
      "id": "s1",
      "wordRange": [0, 3],
      "visual": "macro-skin",
      "productRef": "serum",
      "caption": "熬夜脸，还有救",
      "transition": "cut",
      "dirty": false
    }
  ],
  "audio": { "bgm": "bed-glow", "beatAnchors": [0.5, 1.0, 1.5], "vo": "voice-a" },
  "render": { "engine": "ffmpeg", "fps": 30, "parallelism": 4 }
}
```

**为什么以词为锚点**：

- 改文案不需要重新对时间轴；
- 翻译/多语言变体可以自动重排；
- 字幕、口播、镜头共享同一套时间语义；
- 选择性重生成只需比较 `words` 与 `dirty` 标记。

### 7.4 商品一致性

电商视频最大的技术痛点是：同一件商品在不同镜头里「长得不一样」。

- **开源版**：商品参考图 + 模板约束（构图、颜色、Logo 位置、形状比例），渲染时锁定关键视觉；
- **云端版**：商品/角色一致性模型，做到「同一个模特、同一件商品」；
- **验收**：每个镜头抽帧，与参考图做 CLIP/颜色/结构相似度抽检。

### 7.5 渲染与成本

- 渲染层优先 FFmpeg：字幕烧录、配乐、多尺寸导出、并行；
- 引入 Remotion / HyperFrames 前先复核许可证（Remotion 对公司使用有商业授权要求）；
- 本 MVP 使用 Playwright 逐帧 + FFmpeg，不引入 Remotion；
- 镜头级 `dirty` 标记，只重生成改动镜头；
- 每次生成记录：模型、token/秒数、镜头数、耗时、单价；
- 输出成本账单，批量任务可预估总成本。

### 7.6 合规内建

- 默认不支持替换真人脸，只使用授权数字人；
- 成片自动加「AI 生成」标识（画面角标 + 元数据）；
- 参考片只做结构分析，不二次分发原片；
- 音乐使用授权曲库或自制 BGM；
- 报告卡片不展示未授权人脸特写。

| 能力 | 开源 | 云端（WearAI） |
| --- | --- | --- |

| 批量变体 | ✅ 本地小批量 | 大批量、多语言、成本优化 |
| 模板库 / 品类配方 | ❌ | ✅ 8 大品类 |
| 托管模型 | 用户自带 Key | ✅ 33 个模型 |
| 角色一致性 | ❌ | ✅ |
| 团队协作 / 计费 | ❌ | ✅ |

**对外口径**：WearAI 的品类差异化（覆盖主流工具限制的品类）是云端卖点，不作为开源项目的宣传点。

### 8.1 许可证与实现边界

- ViralForge 自身使用 **Apache-2.0**；
- **不包含、不派生自 Hypit 代码**：Hypit 的自定义许可禁止多租户 SaaS 与商业再分发，本项目只借鉴公开讨论的「以词为锚点」思路，独立实现；
- 不引入 AGPL-3.0 依赖（CozyClay、OpenChatCut、concat 等仅作思路参考）；
- 可借鉴的 MIT / Apache-2.0 配方（video-shotcraft 镜头卡、reelmimic 做法、printfilm 管线、Easel 尺寸规格）使用时保留署名与许可声明；
- 未使用 Remotion / HyperFrames；渲染为 Playwright + FFmpeg，便于单独复核商业许可；
- 上游素材只用于分析，不进入成片；演示关键帧为自制模拟。

## 13. 部署方案

- **本地演示**：`npm run build && npm run preview`，默认 `http://127.0.0.1:4173`；
- **静态托管**：`dist/` 可直接部署到 Vercel / Cloudflare Pages / GitHub Pages（hash 路由，无需服务端）；
- **公网临时链接**：本地服务 + 隧道（用于评审）；
- **正式环境**：需要 Vercel Token 或 Cloudflare 账号；渲染 worker 需独立 Node 容器（FFmpeg + 浏览器），不在静态托管内；
- **当前限制**：执行环境没有 Vercel / GitHub 登录态，无法用「AI 的账号」发布到公网；仓库内提供一键部署配置与说明。

## 14. 风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 平台反爬 / 链接失效 | 无法拆解 | yt-dlp + cookies 可选；失败引导上传；样例库兜底 |
| 无模型 Key | 无法真实生成 | 演示模式：真实结构分析 + 模板渲染；Key 到位即切换 |
| 商品一致性差 | 成片不可用 | 参考图约束 + 抽检 + 云端一致性模型 |
| 版权 / 肖像 | 法务风险 | 自制模拟素材；不换脸；授权数字人；AI 标识 |
| 渲染成本失控 | 商业不可行 | 选择性重生成 + 镜头级成本账单 + 批量预估 |
| 开源被白嫖 | 商业化受阻 | 云端保留模板库、模型、一致性、批量能力 |
| 部署账号缺失 | 无法公网演示 | 本地 + 隧道；提供部署配置，等待 token |

### 18.3 术语

| 术语 | 含义 |
| --- | --- |
| 爆款基因 / DNA | 一条爆款视频的结构化拆解结果 |
| VFML | ViralForge Markup Language，以词为锚点的视频工程 JSON |
| 词锚点 | 用词级时间戳定位镜头与事件，而非固定秒数 |
| 选择性重生成 | 只重做被改动的镜头 |
| 商品一致性 | 同一商品在不同镜头中的视觉一致 |
| 报告卡片 | 可分享的拆解结论公开页 |
